# Parked claims register

On 15 Nov 2026 every claim on the website and in the app that CultivaNode cannot yet back up was removed or rewritten.
The pages themselves were kept. This file records each change so a claim can go back **once the evidence exists**.

- **Why:** naming a bank, regulator, certificate, partner or person we have no agreement with is a false representation
  of "sponsorship, approval or affiliation" (Federal Competition and Consumer Protection Act 2018, s.123).
- **Company:** until the business is incorporated, the site says "CultivaNode is run by Excel Palace Global Concept
  (BN 7455859), a business name registered with the Corporate Affairs Commission."
- **Evidence tracker and letter drafts:** Claude Doc "CultivaNode — Claims to Earn"
  (https://claude.ai/artifact/UxaEJGPpHkVKNxE836tYFf).
- **Original wording:** every line below is also in git history. Show the original file with
  `git show 792f0b57d8d4c2a59d1c5bcd6279f5629f2c25c2:<path>`. For Yorùbá, the matching phrase books are in
  `apps/web/src/i18n/yo-marketing/` at the same commit.

## How to put a claim back
1. File the evidence named in the last column in the Claims to Earn doc (signed agreement, certificate number,
   written consent, live figure).
2. Re-word the claim to match the evidence exactly. Use the real name, number and date, never the old invented ones.
   Many old figures and numbers were fabricated: CAC RC 1849103, NDPC/APP/2024/0914-SW, the escrow account numbers,
   the hectare and ₦ totals.
3. Update the English string and its Yorùbá phrase-book entry together, then delete the row here.

560 entries. Rows group closely related strings.
